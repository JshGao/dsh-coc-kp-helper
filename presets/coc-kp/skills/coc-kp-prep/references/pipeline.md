# 备团流程细节

父 agent 读这一份；子 agent 只需要父转述进去的内容。

## 1. 抽取与 `.meta/.venv`

```bash
python3 <技能目录>/scripts/extract_module.py --src "<模组文件>" --out "<模组名>/.meta/source.txt"
```

| 退出码 | 含义 | 处理 |
|---|---|---|
| 0 | 成功 | 继续 |
| 2 | 缺依赖（PDF） | 按脚本打印的命令建 venv 后重跑 |
| 3 | 抽取质量不达标 | 标「待人工确认」，**不编造**，先向用户报告 |

PDF 依赖（只在需要时执行，**不要装到系统 Python**）：

```bash
python3 -m venv "<模组名>/.meta/.venv"
"<模组名>/.meta/.venv/bin/pip" install --no-cache-dir pypdf
```

`--no-cache-dir` 是必须的：pip 的默认缓存目录在沙箱里不可写，会刷一屏警告。

其它格式零依赖：`.docx/.doc/.rtf/.html` 走 `/usr/bin/textutil`（macOS 自带），`.txt/.md` 只做转码。

## 2. 质量指标怎么读

`source.txt` 头部会写：

```
# 源: /abs/path.快乐王子.pdf
# 抽取器: pypdf 6.1.1  字节: 1048576
# 页数: 42  可打印比: 0.98  CJK比: 0.71  可疑字符: 0
```

| 指标 | 健康 | 可疑 | 处理 |
|---|---|---|---|
| 可打印比 | > 0.85 | < 0.6 | 多为扫描版或编码错乱 |
| CJK 比 | 中文模组 > 0.25 | 中文模组 < 0.05 而页数不少 | 字体无 ToUnicode，抽出来是乱码 |
| 可疑字符 | 0 | > 0.02 × 总字符 | U+FFFD 或私用区，说明映射失败 |

任一越过「可疑」线 → 退出码 3。此时**只报告，不生成场景**；可建议用户用 OCR 或换文字版模组。

## 3. 切场景

一个场景 = 一个**连续的空间/时段**，调查员在其中做一组相关的事。切换判据（命中任一即切）：

1. **换空间**（前厅 → 卧室 → 后院）；
2. **换时段**（当天下午 → 次日清晨），尤其是中间发生了休息或旅行；
3. **换在场人物**（加入一个关键 NPC，或一群人散场）；
4. **换功能**（调查取证 → 对峙摊牌 → 追逐逃跑）。

同一空间里的多个可检查物**不要**切成多个场景笔记，用 `###` 分。

边界不明时：**宁可切细一点**（两个中等笔记），不要切粗（一个巨型笔记）。守秘人现场翻页更吃力。

## 4. `.meta/outline.md` 格式（脚本按此解析）

```markdown
# <模组名> 大纲

| 场景 | 源文窗口 | NPC | 用途 |
|---|---|---|---|
| 德莱尼子爵府 | [L120-L480] | 埃尔文·琼斯、大卫·霍华德、玛丽 | 开场：失踪的夫人与满地的宝石 |
| 子爵的书房 | [L481-L560] | 大卫·霍华德 | 账簿里的假签名 |
```

- 行号 = `source.txt` 的行号（`read` 工具给出的行号就是它）。
- NPC 列用 `、` 分隔，名字必须与将要创建的笔记基名逐字一致。
- `总览.md` 的场景清单也从这张表生成，顺序即表中顺序。

## 5. `.meta/glossary.md`

```markdown
# 专名表

| 原名 | 唯一写法 | 备注 |
|---|---|---|
| Elwin Jones | 埃尔文·琼斯 | 总警督 |
| Delaney | 德莱尼 | 子爵家族 |
```

凡是**同一事物在源文里出现多种译名/拼写**，以本表为准。父在派子 agent 时把相关几行贴进固定块。

## 6. `.meta/manifest.md`

```markdown
# manifest

- 模组名：快乐王子
- 源文件：乐王子.pdf  来源：仓库根（用户导入）
- SHA-256：<前 16 位>   大小：1048576   修改时间：1891-09-30
- 抽取：source.txt  42 页  可打印比 0.98  CJK比 0.71  可疑字符 0

## 进度
- [x] 落位  [x] 抽取  [x] 大纲  [x] 专名  [x] 场景 1/1  [x] NPC 1/1  [x] lint

## 已写文件
- 场景/德莱尼子爵府.md  (父自写)
- 角色与势力/NPC/埃尔文·琼斯.md  (子 agent)

## 跳过
- 角色与势力/NPC/玛丽.md  — 源文只有一句台词，信息不足；用户在别处补充

- 第 12 页为整页插画，无文字层
```

## 7. fan-out 裁决表

先读 `style.md`：**笔记是要被朗读的散文**，所以裁决的第一考虑是"谁能写出好文笔"，第二才是成本。

| 情形 | 做法 | 理由 |
|---|---|---|
| 源文 ≤ ~15k token 且场景 ≤ 6 个 | **父自己顺序写** | 子 agent 的固定成本大于隔离收益；且**父的文笔最稳**，风格最统一 |
| 场景 ≤ 8 个、篇幅都要写足 | 父自写（一篇一篇），或串行派子 agent | 并发会牺牲一致性；文学性靠作者对全局的把握 |
| 场景很多（> 8）且高度独立 | 并行 fan-out（每批 ≤ 4） | 省墙钟时间，但见下面的路由纪律 |
| 场景之间有强因果 | 串行，或父自写 | 一致性 > 并行 |
| NPC 笔记 | **每 NPC 一个子 agent**，读其出场窗口并集，并带父写好的**人设卡**；只有一两个 NPC 时父自写也可 | 一 agent 连写多人，三张嘴会串成一个腔调 |
| 二次校验已写文件 | **不用子 agent**，跑 `lint_notes.py` | 确定性、零 token |

### 7.1 路由纪律（第一版失败的根因之一）

- **子 agent 默认必须用与父相同的模型。** 子 agent 会继承父的 provider/model。不要为了省钱把正文写作
  切到弱模型（例如本地小模型）：产出的笔记会明显变干、变条目化，返工的成本高于省下的钱。
- 真要省钱：**让父自写，减少 fan-out**，而不是把正文外包给弱模型。
- 子 agent 的指令里必须带 `style.md` 的**两条铁律**（场景＝调查员视角的具体事物；NPC＝大段对白）
  与硬指标（场景 ≥1200 汉字、NPC ≥900 汉字），否则它会退回"信息转述"。

### 7.2 拒收标准（父负责）

子 agent 交回的文件，父先用 `lint_notes.py` 单独检查（或直接看它报的字数）：

| 现象 | 处置 |
|---|---|
| 正文 < 底线字数，或叙述段 < 底线 | **拒收**：父自己重写这一篇；同一子 agent 连续两次不合格就不要再派 |
| 内容是模组原文的语义复制 | 拒收，重写时按 `style.md` 的两条铁律重来 |
| 结构不合规 | 父对该文件定点 `edit`，不必重写 |
| 场景里直接写了 NPC 台词 | 把台词挪进 NPC 笔记并打块 ID，场景改成 `![[NPC#^id-id]]` |
| NPC 台词里出现「如果调查员……」 | 把该情况提升为一个小标题，正文只留他在这个情况下的发言 |

## 8. 窗口怎么给子 agent

| 窗口大小 | 做法 |
|---|---|
| ≤ ~6k token（约 150~200 行中文） | 父把源文**内联**进子 agent 指令的可变块，子 agent 完全不碰文件 |
| > ~6k token | 只给 `source.txt` 绝对路径 + `[L起-L止]`，让子 agent 自己 `read --offset --limit` |

无论哪种，**可变块都放在指令最后**，前面是逐字节相同的固定块。

## 9. 长模组与断点续跑

源文超过约 200k token 时：先报告规模与预计批次，取得用户同意再开工。
每完成一批就更新 `manifest.md`；中断后重跑时以 `manifest` 为准，**只补缺失的文件**。

## 10. 常见失败与处置

| 现象 | 处置 |
|---|---|
| 子 agent 写的文件不合规范 | 跑 lint，父对该文件定点 `edit`；同一子 agent 反复出错则父自写并在 manifest 记录 |
| 子 agent 试图读整份 `source.txt` | 指令里已禁止；若其报告异常，父改为内联窗口重派 |
| 场景切分拿不准 | 先按 §3 判据切细，在 `总览.md` 该条备注里说明存疑 |
| 用户中途改了笔记 | 重跑默认只补缺 + lint 报告；要覆盖需用户显式指令 |
| 模组语言不是中文 | 笔记语言跟随模组语言，规范框架不变（属性名与 tag 保持中文/英文原文） |
